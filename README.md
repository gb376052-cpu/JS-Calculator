# 🧮 Simple Calculator Web App

A clean, responsive, and fully functional Calculator web application built using HTML, CSS, and JavaScript. This project performs basic arithmetic operations with an intuitive user interface.

## ✨ Features
* Perform basic mathematical operations: Addition (+), Subtraction (-), Multiplication (*), and Division (/).
* Clear Screen (C) and Delete (DEL) functionality.
* Responsive design that works seamlessly across desktop and mobile devices.
* Modern and minimalist user interface.

## 🛠️ Tech Stack
* **HTML5**: Structure of the calculator.
* **CSS3**: Styling, layout, and responsive design.
* **JavaScript (ES6)**: Core calculation logic and interactive button handling.
