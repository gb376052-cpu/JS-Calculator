# 🧮 JavaScript Calculator

A sleek, responsive, and fully functional Calculator web application built using HTML, CSS, and JavaScript. This project handles arithmetic operations seamlessly with a clean user interface.

## ✨ Features
* Perform basic mathematical calculations: Addition (+), Subtraction (-), Multiplication (*), and Division (/).
* Clear screen (C) and delete functionality.
* Responsive, clean, and modern user interface optimized for various screen sizes.

## 🛠️ Tech Stack
* **HTML5**: Structure and markup of the calculator interface.
* **CSS3**: Styling, layout, and visual presentation.
* **JavaScript (ES6)**: Core calculation logic, event handling, and DOM updates.
